# Treasure Hunt

Охота за сокровищами для Rust. Игрок находит в ящиках карту сокровищ, активирует её в исследовательском столе, и где-то на карте появляется сундук с лутом.

![Карта сокровищ](screenshots/main.png)

**Платформа:** Oxide/uMod · Carbon  **Язык:** C#  **Версия:** 2.9.25  **Автор:** Avgust

## Возможности

- **4 редкости карт**: обычная, редкая, эпическая, легендарная. У каждой свой лут, название, описание и иконка (скин из Workshop)
- **Выпадение из ящиков**: правила по префабу ящика (точное совпадение, «содержит», «начинается с»), шанс для каждого правила, один бросок на ящик
- **Активация через исследовательский стол**: положил карту, и запускается поиск места для сундука
- **Умный поиск позиции**: на заданном расстоянии от игрока, на ровной земле, не в воде и не у берега, не на скалах, деревьях и постройках, подальше от монументов и чужих баз
- **Сундук с таймером**: исчезает по истечении времени или когда опустошён, есть лимит активных сундуков на игрока
- **Маркеры**: текст и рамка над сундуком плюс маленький HUD на экране со списком активных сокровищ
- **Таблицы лута** для каждой редкости: мин/макс предметов, отдельный бросок на оружие
- **Настоящие кастомные предметы** через CustomItemDefinitions: своё название и описание прямо в инвентаре, без ванильного текста
- **RU/EN**: язык задаётся в конфиге или определяется автоматически по игроку
- **Админ-панель** в игре и API для других плагинов

## Зависимости

- [CustomItemDefinitions](https://umod.org) — необязательно, но нужно для полноценного описания карт в инвентаре. Без него плагин работает в упрощённом режиме и предупреждает об этом в консоли.

## Установка

1. Скопируй `TreasureHunt.cs` в `oxide/plugins` (или `carbon/plugins`).
2. Конфиг появится в `oxide/config/TreasureHunt.json`.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/treasure help` (или `/th`) | все | Справка |
| `/treasure hud` / `/treasure clearhud` | все | Показать / скрыть HUD сокровищ |
| `/treasure ui` | админ | Админ-панель |
| `/treasure give normal\|rare\|epic\|legendary` | админ | Выдать себе карту |
| `/treasure name ru\|en <тип> <текст>` | админ | Переименовать карту |
| `/treasure clear` / `/treasure clearall` | админ | Удалить свои / все активные сундуки |

## Права

| Право | Что даёт |
|---|---|
| `treasurehunt.admin` | Админ-команды и панель (админы сервера по умолчанию тоже) |

## API

```csharp
[PluginReference] Plugin TreasureHunt;

TreasureHunt?.Call("API_GiveMap", player, "rare"); // normal / rare / epic / legendary
```

## Как устроено

- **Поиск позиции.** Несколько попыток со случайной точкой в кольце от min до max расстояния. Каждая проверяется на наклон земли, перепад высот, воду (с шагом и запасом по высоте), топологию (океан, озеро, река), коллайдеры скал и построек, дистанцию до монументов.
- **Кастомные предметы.** Карты регистрируются через CustomItemDefinitions на базовом предмете без ванильного описания. Тексты передаются обычными строками, а не своими Translate-токенами, иначе клиент Rust показывает вместо текста сам токен.
- **Иконки.** PNG хранятся в FileStorage сервера под собственным CRC32.
- **Совместимость со старыми версиями.** Карты, выданные прошлыми версиями плагина (старые префиксы и формат note), распознаются и продолжают работать.
